# Prompts Importantes

Este arquivo registra prompts úteis para continuar evoluindo o projeto com IA sem perder contexto.

## Revisar arquitetura

```text
Revise a arquitetura do OmniQA Framework e identifique inconsistências entre código, README, site e documentos em docs. Priorize problemas reais de manutenção, execução e clareza para portfólio.
```

## Criar novo cenário Web

```text
Adicione um novo cenário Web seguindo o padrão atual: Playwright, Page Object Model, test.step com evidência por etapa e dados em support quando fizer sentido. Atualize o plano de testes e a matriz de rastreabilidade.
```

## Criar novo cenário API

```text
Adicione um novo cenário de API com Playwright, mantendo validação de status, contrato e comportamento. Atualize o plano de testes de API e a matriz de rastreabilidade.
```

## Evoluir Mobile com cuidado

```text
Analise os testes Mobile Android e iOS antes de alterar. Preserve a separação por plataforma, use Screen Objects, mantenha evidência por etapa e não prometa reaproveitamento de código que ainda não existe.
```

## Melhorar relatórios

```text
Melhore os relatórios do OmniQA Framework mantendo o design atual em scripts/report-styles.ts. Evite dependências desnecessárias e garanta que os comandos avulsos e regressivos continuem abrindo os relatórios corretamente.
```

## Preparar release ou publicação

```text
Faça uma revisão final para publicação do projeto: comandos, documentação, links, GitHub Pages, relatórios, consistência dos nomes e instruções para execução local.
```

## Investigar falha de teste

```text
Investigue a falha do teste abaixo. Leia primeiro o spec, Page Object ou Screen Object correspondente, depois confira configuração e evidências. Proponha ou implemente a correção mais simples que preserve o padrão do projeto.
```
