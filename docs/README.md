# Documentação

Esta pasta organiza a documentação do OmniQA Framework por finalidade.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `strategy/` | Estratégia de QA, decisões de abordagem e plano de execução |
| `test-plans/` | Planos de teste por frente: API, Web, Mobile e Performance |
| `traceability/` | Matriz de rastreabilidade entre IDs, plataformas e cenários |
| `ai-notes/` | Contexto, prompts, padrões e próximos passos para trabalho assistido por IA |

## Notas

- Os documentos devem refletir o estado real do código.
- Mudanças em cenários automatizados devem atualizar o plano de teste correspondente e a matriz de rastreabilidade.
- Mudanças feitas com apoio de IA devem respeitar os padrões descritos em [Padrões para IA](./ai-notes/ai-guidelines.md).
