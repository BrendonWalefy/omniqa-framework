# Roteiro de Apresentacao

## Abertura

Apresentar a estrategia como uma solucao modular para tres plataformas: Web, API e Mobile, com performance como diferencial.

## Mensagem principal

A entrega foi organizada em um monorepo modular para manter padronizacao sem acoplar as plataformas. A estrategia prioriza risco, piramide de testes, reuso de componentes e evidencias automaticas.

## Ordem sugerida

1. Explicar a estrategia de QA.
2. Mostrar matriz de rastreabilidade.
3. Executar testes de API.
4. Executar testes Web.
5. Mostrar estrutura Mobile.
6. Apresentar relatorios e evidencias.
7. Comentar proximos passos e melhorias.

## Pontos para destacar

- Decisoes foram tomadas por risco e estabilidade.
- Nem tudo precisa virar E2E.
- API cobre validacoes rapidas e baratas.
- Web cobre jornadas criticas.
- Mobile reutiliza cenarios e separa seletores por plataforma.
- Relatorio consolidado facilita tomada de decisao.
